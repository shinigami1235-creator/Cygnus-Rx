# Cygnus Rx

Prescriptions and laboratory requests for the clinic, from Cygnus Solutions.
This repository is the app itself, served by GitHub Pages at
https://shinigami1235-creator.github.io/Cygnus-Rx/.

Open that address on the PC, a phone or a tablet and install it. It works
offline after that, and each device keeps its own records.

The project source, Cygnus Rx Link and the tests are in
`Coding Projects\Cygnus Rx` on the clinic laptop. Publish a change by copying
that folder's `web` contents here, leaving out `web\public`, after running
`node scripts/build-web.mjs` so installed copies pick up the new version.
